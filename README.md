# All-Rounder Discord Bot

## Included
- Slash commands
- Moderation
- Utility commands
- Fun commands
- Server/user info
- Welcome messages
- Ticket system
- Economy
- Basic automod
- SQLite database

## Setup
1. Install Python 3.11+.
2. Run `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env`.
4. Put your Discord bot token in `.env`.
5. Enable **Server Members Intent**, **Message Content Intent**, and **Presence Intent** in the Discord Developer Portal.
6. Start with `python bot.py`.

### Pterodactyl
Startup command:
`python bot.py`

### Railway
Start command:
`python bot.py`

Never upload your real `.env` or bot token to GitHub.
